# 我的第一个上线项目

一个**零依赖、零构建**的静态网站模板，用来跑通「写代码 → 推 Git → 导入 EdgeOne Makers → 绑定域名」这条完整链路。

## 它长什么样

- 深色玻璃拟态风格的落地页
- 一个可点击的计数器（数据存在浏览器本地，关掉再开还在）
- 根据当前时间显示不同问候语
- 完全响应式，手机上也好看

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架：决定了页面上有哪些内容 |
| `style.css` | 页面样式：颜色、间距、圆角、动画 |
| `app.js` | 页面行为：点击计数、问候语、自动年份 |
| `.gitignore` | 告诉 Git 哪些文件不需要提交 |

三个文件都是**小白级中文注释**，每一段都在解释"这行是干嘛的"，适合当作学前端的第一份教材。

## 本地预览

方式一（最省事）：直接双击 `index.html`，用浏览器打开。

方式二（更接近真实环境）：

```bash
python3 -m http.server 8080
```

然后浏览器访问 <http://localhost:8080>。

## 部署到 EdgeOne Makers

1. 登录腾讯云，开通 **EdgeOne Makers**（免费）
2. 新建项目 → 选择 **从 Git 导入** → 授权并选中本仓库
3. 关键配置：
   - **框架预设**：静态站点 / 其他
   - **构建命令**：留空（本项目不需要编译）
   - **输出目录**：`./`
4. 点击部署，等待完成，会先给一个平台自带的访问地址
5. 在「自定义域名」里填入你自己的域名，然后回域名后台加一条 CNAME 解析记录
6. 等 DNS 生效，平台会自动签发 HTTPS 证书

> **关于备案**：如果选择国内节点，域名必须先完成 ICP 备案；选择海外节点则无需备案，可立即使用。

## 下一步可以改什么

- 把 `index.html` 里的标题和文案换成你自己的
- 在 `:root` 里改几个颜色变量，整站配色立刻跟着变
- 想加页面，就再复制一份 HTML 文件，把 `<title>` 和内容改掉即可
