# 像素地牢 · 深入地底

一个**零依赖、零构建**的像素风地牢冒险小游戏，纯前端实现（原生 HTML + CSS + JavaScript）。

双击 `index.html` 就能玩 —— 不用装 Node、不用 `npm install`、不用任何打包工具。

## 怎么跑

**方式一（最简单）**：双击 `index.html`，浏览器直接打开就能玩。

**方式二（推荐）**：在项目根目录执行下面这行，然后访问 <http://localhost:8000>

```bash
python3 -m http.server 8000
```

用本地服务器打开的好处是：以后想加音效文件、图片素材时，不会被浏览器的跨域安全策略拦住。

> **部署说明**：这是一个纯静态站点，没有任何构建步骤。在 EdgeOne Makers 上导入本仓库时，
> 构建命令留空、输出目录填仓库根目录（`.`）即可。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | `W` `A` `S` `D` 或 方向键 | 左下角十字键 |
| 攻击 | `J` 或 空格 | 右下角「攻击」 |
| 确认 / 开始 | `Enter` | 右下角「开始」 |

手机上会自动出现虚拟手柄（CSS 用 `@media (hover: none) and (pointer: coarse)` 判断，
只有"没有鼠标、只有粗指针"的设备才显示），电脑上完全看不到这一层。

## 四个可选角色

开始游戏后先选角色。四个人**共用同一套行为代码**，区别全在数值上 ——
这是典型的"数据驱动设计"：加内容不用改代码，只改 `src/config.js` 里的数据表。

| 角色 | 职业 | 武器 | 特点 | 生命 | 移速 | 单击伤害 |
| --- | --- | --- | --- | --- | --- | --- |
| 大 | 狂战士 | 巨斧 | 攻击范围最大、击退最猛，但移速最慢 | 7 | 70 | 3 |
| 祖 | 秘法师 | 法杖 | **唯一的远程角色**，隔空放火球灼烧 | 5 | 76 | 2 |
| 马 | 游侠 | 短剑 | 移速最快、出手极快，靠贴身连砍输出 | 5 | 104 | 1 |
| 金 | 圣骑士 | 长剑 | 生命最厚，每次受伤固定减免 1 点 | 8 | 64 | 2 |

选人界面里可以用左右键循环切换，按攻击键或回车确定；死亡后也会回到这里，
方便你换个角色再来一把。

## 游戏内容

- **随机地牢**：每一层的地图都是现生成的，房间和走廊的布局每次都不一样
- **探索小地图**：走到哪儿点亮哪儿，帮你记住走过的路
- **多种敌人**：各有不同的血量、移速和 AI 行为
- **掉落道具**：金币（加分）、药水、补血的心
- **楼梯往下**：找到楼梯进入下一层，越往下越难 —— 血量不会因换层而恢复
- **打击反馈**：命中火花、击杀血花、屏幕震动、击退位移，全都做足了

## 文件结构

`index.html` 里的 `<script>` 顺序**就是执行顺序**，有依赖关系的必须排在前面：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架：搭出 canvas 和触屏手柄，按顺序加载所有模块 |
| `style.css` | 页面样式：画布居中与整体放大、触屏手柄的显隐控制 |
| `src/config.js` | 全局配置：调色板、玩家常量、**四名角色的数值表**都在这里 |
| `src/audio.js` | 用 WebAudio 现场合成 8-bit 音效，不需要任何音频文件 |
| `src/input.js` | 键盘 + 触屏两套输入源，区分「按住」和「刚按下」 |
| `src/art.js` | 美术数据：用「字符画」定义所有角色、敌人、道具的样子 |
| `src/sprites.js` | 把字符画「烤」成真正的 canvas 图像，并生成程序化地砖 |
| `src/font.js` | 点阵字体：所有界面文字都由它绘制，支持中文 |
| `src/dungeon.js` | 随机地牢生成：房间、走廊、瓦片地图 |
| `src/entities.js` | 实体：玩家、敌人、道具、投射物 |
| `src/game.js` | 游戏主控：状态机、主循环、相机、碰撞、渲染 |
| `src/main.js` | 启动入口：把游戏「点火」跑起来，必须排在最后 |

## 技术特点

- **像素风的来源**：canvas 内部真实分辨率只有 `320×192`，CSS 再把它拉伸到全屏。
  两个尺寸差得越大，像素块就越粗犷。
- **美术即数据**：角色外形用字符画写在 `art.js` 里，一个字母代表一种颜色。
  四个角色只抓一个大色块特征（光头胡子／尖帽／兜帽／钢盔），保证缩到 12×14 也一眼能分辨。
- **零音频文件**：所有音效都是实时算出来的波形，所以仓库里一个 `.mp3` 都没有。
- **中文点阵字体**：`font.js` 把汉字实时渲染成点阵再缓存，所以不依赖任何字体文件。
- **斜向不加速**：移动向量做了归一化，八个方向速度完全一致，避免"斜着走更快"的漏洞。
- **按住不会连发**：输入层严格区分 `held`（按着）和 `pressed`（这一帧刚按下），
  从根上杜绝"按住攻击键无限连击"这种经典 bug。
